# Teknik Skill

## Instructions

1. log alt yapısı kur
2. commentleri ingilice yaz
3. snake case teknik

Apply these rules on every code change:

- Set up and use the project logging infrastructure. Do not use raw print for application flow.
- Write all code comments in English.
- Name files, functions, variables, and modules in snake_case.
